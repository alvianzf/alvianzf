Career coaching for Indonesian job seekers who want to work abroad. Frontend, [backend](https://github.com/alvianzf/hiredwithandi-be), [admin panel](https://github.com/alvianzf/hiredwithandi-admin), and a [job tracker](https://github.com/alvianzf/hirewithandi-FE). Four repos. One person. The bus factor is not great and the bus is me.

### 🚀 [Tick PHP](https://github.com/alvianzf/tick-php-framework)

A PHP framework I built from scratch, because the world's supply of PHP frameworks was clearly running low. Routing, dependency injection, ORM, JWT auth, auto-generated Swagger docs. This is what I do to relax. I'm very normal.
